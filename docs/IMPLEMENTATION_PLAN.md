# Plan d’implémentation (proposé)

## Phase 0 — Cadrage (1 à 2 semaines)

- Ateliers métier : règles tontine, cas d’exception, litiges.
- Atelier conformité : KYC/AML, contraintes réglementaires.
- Validation architecture + choix des prestataires paiement.

## Phase 1 — MVP (6 à 10 semaines)

- Auth + KYC basique.
- Gestion tontines et cycles.
- Paiements WAVE + carte (sandbox puis production).
- Dashboard admin minimal.
- Journal d’audit + reporting de base.

## Phase 2 — Sécurité renforcée (2 à 4 semaines)

- MFA avancée, anti-fraude, alerting sécurité.
- Tests de charge et durcissement infra.
- Pentest + remédiation.

## Phase 3 — Extension produit

- Score de fiabilité membre.
- Multi-devise / multi-pays.
- API partenaire (B2B) et comptabilité avancée.

## KPIs à suivre

- Taux de paiement réussi.
- Taux de retard de cotisation.
- Temps moyen de résolution litige.
- Taux de churn membres.
- Disponibilité plateforme.
